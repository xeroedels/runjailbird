## Langkah instalasi dependensi

```
1. Lakukan clone repositori dengan git clone <url git repositori>
2. masuk ke dalam folder project pada git dengan cd nama_project
3. npm instsall
```

## Perintah untuk menjalankan project

```
 npm run serve kemudian akses http://localhost:8080/
```

## Project setup

```
npm install
```
